# Лабораторная работа №3: Вёрстка макета с помощью Flexbox и Grid

**Выполнила:** Шалыгина Елена, группа 932403

**Вариант:** 11 (Тема «Фотограф и визуальный сторителлер»)

## Описание работы

В проекте реализованы следующие элементы согласно техническому заданию:
* Страница из лабораторной №2 дополнена разделами «Фотопроекты» и «Настройки съёмки», в навигацию добавлены ссылки на новые разделы.
* Навигационное меню выполнено на Flexbox: горизонтальное, с `flex-wrap`, при нехватке места ссылки переносятся на новую строку.
* Раздел «Фотопроекты»: три карточки `article` в ряд на Flexbox. В каждой карточке есть превью, название и локация съёмки.
* Адаптивность карточек: 1 колонка на мобильных устройствах, 2 колонки от 600 px (планшеты) и 3 колонки от 900 px (десктопы).
* Раздел «Настройки съёмки» реализован на CSS Grid: три блока (ISO, выдержка, диафрагма), в каждом иконка, параметр и значение.
* Адаптивность сетки по варианту: 1 колонка на мобильных устройствах и 3 колонки на планшетах и десктопах. Для колонок использован `minmax(0, 1fr)`, чтобы длинные слова не распирали сетку.
* Добавлены медиазапросы для планшетов и мобильных устройств, горизонтальная прокрутка отсутствует.
* В семантике добавлены тег `<meta name="description">` и атрибуты `alt` с описанием каждого кадра. Для карточек использован тег `article`.
* Контрастность текста и фона не менее 4.5:1.

Код веб-страницы валиден и успешно проходит проверку через W3C Validator.
